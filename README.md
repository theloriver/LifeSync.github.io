# LifeSync — ITCC298 Final Website

This is a complete static website with five required pages and a working application prototype.

## Pages

- `index.html` — Home
- `about.html` — About Me
- `prototype.html` — Interactive LifeSync application
- `marketing.html` — Marketing
- `guide.html` — User Guide

## Other files

- `site.css` — Website styles
- `app.css` — Application styles
- `script.js` — Calendar, budget, tasks, and theme functionality
- `assets/` — Actual screenshots of the prototype (sample entries)

## Publish on GitHub Pages

1. Extract the ZIP file to your computer.
2. Open your GitHub repository `theloriver.github.io`.
3. Upload **all extracted files and the assets folder** to the repository root (not the ZIP itself).
4. Commit the changes. If GitHub asks, confirm overwriting your old `index.html`.
5. In Settings > Pages, use branch `main` and folder `/ (root)`.
6. Visit `https://theloriver.github.io/` once deployment finishes.

The app is a classroom prototype. It stores entries in browser local storage only. It does not connect to a bank, process payments, or sync data to a cloud account. External calendar integrations are planned, not implemented.
