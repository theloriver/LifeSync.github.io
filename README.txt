LIFESYNC — ITCC298 PROTOTYPE

FILES
index.html   Website layout and content
style.css    Layout, responsive design, light/dark theme
script.js    Calendar, budget, tasks, and browser storage

HOW TO RUN
1. Keep index.html, style.css, and script.js in the same folder.
2. Double-click index.html to open it in Chrome or Edge.
3. Use the navigation to add events, expenses, and tasks.

IMPORTANT
This is a local classroom prototype. Data is stored in your browser
on this device only. It does not connect to banks, cloud accounts,
Google Calendar, Outlook, or Google Maps.

FUTURE IDEAS
Calendar integrations, shared planning, travel, and cloud sync.
